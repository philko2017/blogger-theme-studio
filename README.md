## 🌟 核心功能特色

- **🎛️ 視覺化即時調色與排版**
  - **網格佈局**：自由切換 1 欄（極簡清單）、2 欄（經典卡片）或 3 欄（精巧網格），自訂卡片間距與版心寬度。
  - **精緻幾何**：滑桿微調卡片圓角（0~28px）、陰影深度（無陰影／細緻微陰影／立體浮雕）與邊框線條。
  - **5 大主題預設**：內建現代科技靛藍、純粹黑白極簡、北歐森林翡翠、人文雜誌琥珀、深邃極客紫等風格。

- **🌗 完美適配深淺色模式（Dark Mode）**
  - 整合防載入閃爍（Anti-FOUC）機制與 CSS 變數系統。
  - 獨立調配夜間模式色彩，確保標籤、按鈕與文字在暗黑底色下維持清晰的高對比閱讀體驗。

- **🖼️ 3 格精選圖文視覺選單（Visual Banners）**
  - 位於首頁頂端的視覺焦點導航區，支援自訂 3 組精選主題圖文。
  - 可自由更換背景圖片 URL、設定目標超連結、自訂雙層浮動標題與前綴小語。
  - 內建暗色漸層遮罩與滑鼠懸停微放大（Zoom-in）動效。

- **📌 Blogger 原生置頂文章支援（Featured Post）**
  - 完整相容 Blogger 後台「版面配置」的原生精選文章小工具。
  - 免改代碼，直接在 Blogger 後台勾選即可將任意文章設為首頁 Hero 寬版置頂大卡。

- **👤 側邊欄作者簡介卡片（Author Bio Card）**
  - 100% 穩定呈現於前台，不受 Blogger 舊版個人資料限制。
  - 支援設定個人頭像、姓名、身分職稱、自我介紹與 GitHub / Twitter / Email 社群按鈕。

- **⚡ 一鍵代碼編譯與導出**
  - 瀏覽器端即時編譯，支援「一鍵複製 XML 程式碼」與「一鍵下載 XML 檔案」。

## 🚀 快速開始：如何套用至 Google Blogger

只需要簡單 4 個步驟，即可讓您的 Blogger 網誌換上新版型：

1. **設計版面**：
   - 開啟本編輯器，依照您的喜好調整顏色、欄數、卡片細節與作者資訊。
   - 調整滿意後，點擊右上角 **「一鍵複製 XML 程式碼」**。

2. **備份現有主題（重要）**：
   - 登入 [Google Blogger 後台](https://www.blogger.com)，點擊左側選單的 **「主題」**。
   - 在「我的主題」右上角「自訂」按鈕旁，點擊 **倒三角形箭頭 (▼)**，選擇 **「備份」** 下載備份檔。

3. **貼上新主題代碼**：
   - 再次點擊倒三角形箭頭，選擇 **「編輯 HTML」**。
   - 在代碼區按 `Ctrl + A`（Mac 為 `Cmd + A`）全選清空，並貼上剛複製的 XML 代碼。

4. **儲存發布**：
   - 點擊右上角橘黃色 **「儲存」**（磁碟片圖示）。
   - 點擊左側選單最下方的「瀏覽網誌」，即可看到套用後的現代極簡卡片版型！
