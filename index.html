如何套用至 Google Blogger 後台（完整步驟）

        
      

      

        
    
          
  1. 
            第一步：備份現有主題（建議）
    
            登入 Google Blogger 後台，點擊左側選單的 「主題」。在「我的主題」右上角的「自訂」按鈕旁邊，點擊 倒三角形選單 (▼)，選擇 「備份」 下載備份檔案。
          
    2. 
          
  2. 
            第二步：進入 HTML 編輯模式
    
            再次點擊倒三角形選單，選擇 「編輯 HTML」。
          
    3. 
          
  3. 
            第三步：貼上新產生的 XML 代碼
    
            使用快捷鍵 Ctrl + A (Mac 為 Cmd + A) 全選所有舊代碼並刪除清空。
    
            點擊本編輯器右上角 「一鍵複製 XML 程式碼」，貼上 (Ctrl + V) 至 Blogger 後台編輯器。
          
    4. 
          
  4. 
            第四步：儲存並查看部落格
    
            點擊 Blogger 編輯器右上角橘黃色的 「儲存 (磁碟片圖示)」。儲存完成後，點擊左下角「瀏覽網誌」，即可看到前台與編輯器完全一致的現代極簡卡片版型！
          
    5.
